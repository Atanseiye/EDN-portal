# EDNAi multilingual documentation

EDNAi provides first-class developer documentation in all four languages exposed by the platform:

| Language | Hosted guide | Repository guide |
| --- | --- | --- |
| English / Nigerian English | `/guide/en` | `docs/en/getting-started.md` |
| Yorùbá | `/guide/yo` | `docs/yo/ibere.md` |
| Hausa | `/guide/ha` | `docs/ha/getting-started.md` |
| Igbo | `/guide/ig` | `docs/ig/getting-started.md` |

All four guides document the same engineering contract: SDK use, HTTP integration, prompting, JSON mode, evaluation, Dataset Studio, QLoRA adaptation, deployment/runtime modes, provenance verification and the official Nigerian-language ASR registry.

The source code, endpoint names and model identity remain unchanged across translations.
