# PowerRights N-ATLaS LLM

ZeroGPU inference service for the official `NCAIR1/N-ATLaS` model.

Required Space secret: `HF_TOKEN` from a Hugging Face account that has accepted the N-ATLaS gated-model terms.

Required hardware: **ZeroGPU (free)**.

Attribution: N-ATLaS is an initiative of the Federal Ministry of Communications, Innovation and Digital Economy, and powered by Awarri Technologies.
