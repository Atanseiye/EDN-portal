EDNAi yana ba developer hanya guda mai daidaito don haɗa, gwadawa, kimantawa, daidaitawa da turawa model na hukuma NCAIR1/N-ATLaS.

N-ATLaS kawai.

EDNAi baya yarda a maye gurbin N-ATLaS da wani model. Qualifying runtime dole ya tabbatar da model ID NCAIR1/N-ATLaS.

1. Python SDK

from ednai import EDNAi

ai = EDNAi(base_url="https://ednai-6znf.onrender.com")
result = ai.generate(
    "Ka bayyana menene API.",
    system="Ka amsa da Hausa mai sauƙi.",
    temperature=0.2,
    max_tokens=300,
)
print(result.text)

2. TypeScript SDK

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({
  baseUrl: "https://ednai-6znf.onrender.com"
});
const result = await ai.generate("Ka bayyana API da Hausa.");
console.log(result.text);

3. OpenAI-compatible HTTP

POST /v1/chat/completions
{
  "model": "NCAIR1/N-ATLaS",
  "messages": [
    {"role":"user","content":"Ka bayyana transformer attention."}
  ]
}

4. Prompt da JSON mode

Yi amfani da system prompt domin saita harshe, salo ko ƙa'ida. Ka bar JSON mode a kashe idan kana son amsa ta rubutu. Ka kunna shi ne kawai idan application ɗinka yana bukatar JSON mai tsari.

5. Evaluation

ednai eval benchmarks/natlas_smoke.jsonl \
  --base-url https://ednai-6znf.onrender.com

Evaluation Workbench yana gudanar da gwaje-gwajen regression na harsuna da yawa, JSON validity, kalmomin da dole su bayyana/kar su bayyana, da latency.

6. Dataset Studio

Dataset Studio yana karɓar messages[] ko instruction/input/output JSONL, yana duba kowace row, yana normalize data sannan ya fitar da training-ready JSONL.

7. Fine-tuning

python fine_tuning/train_qlora.py \
  --dataset prepared.jsonl \
  --output-dir outputs/my-natlas-adapter

QLoRA/LoRA adapter yana farawa kai tsaye daga NCAIR1/N-ATLaS.

8. Runtime modes

  • ZeroGPU: hosted N-ATLaS runtime don development da demo; free quota na iya yin queue ko ƙarewa na ɗan lokaci.
  • Local Transformers: loda official N-ATLaS weights a server naka.
  • OpenAI-compatible N-ATLaS: haɗa EDNAi da endpoint da ke hidimar N-ATLaS na gaske.

9. Speech Studio da ASR

EDNAi yana ba developer damar amfani da official NCAIR speech-recognition models ta POST /v1/audio/transcriptions, Python/TypeScript SDK, CLI da Speech Studio.

result = ai.transcribe("audio.wav", language="hausa")
print(result.text)
print(result.model)

EDNAi yana tabbatar da cewa model ID da aka dawo da shi ya dace da harshen da aka zaɓa; baya yarda da ASR model substitution.

10. Official speech models

  • Nigerian English — NCAIR1/NigerianAccentedEnglish
  • Yorùbá — NCAIR1/Yoruba-ASR
  • Hausa — NCAIR1/Hausa-ASR
  • Igbo — NCAIR1/Igbo-ASR

Cikakken repository guide: docs/ha/getting-started.md.

Use Case Studio

EDNAi yana da workflow na N-ATLaS guda takwas: multilingual chatbot, translation, educational tools, cultural preservation, government services, digital inclusion, research applications da original song-lyrics generation.

result = ai.run_use_case(
    "education",
    {
        "topic": "Photosynthesis",
        "learner_level": "JSS 2",
        "objective": "Ka bayyana yadda tsiro ke yin abinci.",
        "format": "lesson_quiz"
    },
    language="hausa"
)
print(result.text)

Ana kuma samun workflows ɗin ta GET /v1/use-cases, POST /v1/use-cases/{use_case}, TypeScript da CLI. Song generation rubutattun lyrics ne kawai; baya ƙara wani audio model.
