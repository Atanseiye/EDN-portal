Build with N-ATLaS.

EnglishYorùbá

EDNAi gives Nigerian developers one stable layer for calling, evaluating, adapting and deploying NCAIR1/N-ATLaS.

Python SDK

from ednai import EDNAi

ai = EDNAi(base_url="https://your-gateway")
result = ai.generate(
    "Explain transformer attention simply.",
    temperature=0.2,
)
print(result.text)

TypeScript SDK

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({ baseUrl: "https://your-gateway" });
const result = await ai.generate("Ka bayyana API da Hausa.");
console.log(result.text);

Evaluate

ednai eval benchmarks/natlas_smoke.jsonl \
  --base-url http://localhost:8000 \
  --output report.json

Adapt

The included QLoRA starter trains lightweight adapters directly on N-ATLaS using NF4 4-bit quantization and LoRA.

python fine_tuning/prepare_data.py --input raw.jsonl --output prepared.jsonl
python fine_tuning/train_qlora.py --dataset prepared.jsonl --output-dir outputs/adapter

Full source documentation lives in docs/en/getting-started.md.
