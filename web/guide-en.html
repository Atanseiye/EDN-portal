EDNAi provides one stable developer layer for integrating, testing, evaluating, adapting and deploying the official NCAIR1/N-ATLaS model.

N-ATLaS only.

EDNAi rejects model substitution. Qualifying inference must identify the upstream model as exactly NCAIR1/N-ATLaS.

1. Python SDK

from ednai import EDNAi

ai = EDNAi(base_url="https://ednai-6znf.onrender.com")
result = ai.generate(
    "Explain prepaid electricity metering simply.",
    system="Answer clearly in Nigerian English.",
    temperature=0.2,
    max_tokens=300,
)
print(result.text)

2. TypeScript SDK

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({
  baseUrl: "https://ednai-6znf.onrender.com"
});
const result = await ai.generate("Ka bayyana API da Hausa.");
console.log(result.text);

3. OpenAI-compatible HTTP

POST /v1/chat/completions
{
  "model": "NCAIR1/N-ATLaS",
  "messages": [
    {"role":"user","content":"Kí ni API?"}
  ],
  "temperature": 0.2,
  "max_tokens": 300
}

4. Prompting and JSON mode

Use a system message to request language, tone or task constraints. Leave JSON mode off for normal prose. Enable it only when the application requires machine-readable JSON.

5. Evaluation

ednai eval benchmarks/natlas_smoke.jsonl \
  --base-url https://ednai-6znf.onrender.com \
  --output report.json

The browser Evaluation Workbench supports multilingual regression cases, required/forbidden strings, JSON validity and latency reporting.

6. Dataset Studio

Dataset Studio accepts chat-format messages[] or instruction/input/output JSONL, validates each record, normalizes the data and produces training-ready JSONL without intentionally persisting the uploaded dataset.

7. Fine-tuning

python fine_tuning/prepare_data.py --input raw.jsonl --output prepared.jsonl
python fine_tuning/train_qlora.py \
  --dataset prepared.jsonl \
  --output-dir outputs/my-natlas-adapter

The starter derives QLoRA/LoRA adapters directly from NCAIR1/N-ATLaS.

8. Runtime modes

  • ZeroGPU: hosted direct N-ATLaS runtime for demos and development; free quota can queue or temporarily exhaust.
  • Local Transformers: load official N-ATLaS weights on your own machine/server.
  • OpenAI-compatible N-ATLaS: point EDNAi at an upstream endpoint that truly serves N-ATLaS.

9. Speech Studio and ASR

EDNAi exposes the official NCAIR speech-recognition models through POST /v1/audio/transcriptions, the Python/TypeScript SDKs, CLI and browser Speech Studio.

result = ai.transcribe("audio.wav", language="yoruba")
print(result.text)
print(result.model)
curl -X POST https://ednai-6znf.onrender.com/v1/audio/transcriptions \
  -F 'language=yoruba' \
  -F 'file=@audio.wav'

The returned model ID is checked against the selected language. EDNAi rejects ASR model substitution.

10. Official speech model registry

  • Nigerian English — NCAIR1/NigerianAccentedEnglish
  • Yorùbá — NCAIR1/Yoruba-ASR
  • Hausa — NCAIR1/Hausa-ASR
  • Igbo — NCAIR1/Igbo-ASR

Use Case Studio

EDNAi includes eight structured N-ATLaS workflows: multilingual chatbot, translation, educational tools, cultural preservation, government services, digital inclusion, research applications and original song-lyrics generation.

result = ai.run_use_case(
    "education",
    {
        "topic": "Photosynthesis",
        "learner_level": "JSS 2",
        "objective": "Explain how plants make food.",
        "format": "lesson_quiz"
    },
    language="english"
)
print(result.text)

The same workflows are available through GET /v1/use-cases, POST /v1/use-cases/{use_case}, TypeScript and the CLI. Song generation is text-only lyrics; it does not introduce another audio model.
