EDNAi jẹ́ layer kan fún developer láti so model osise NCAIR1/N-ATLaS mọ́ app, dán án wò, ṣe evaluation, adaptation àti deployment.

N-ATLaS nìkan.

EDNAi kò gba kí model míì rọ́pò N-ATLaS. Qualifying runtime gbọ́dọ̀ dá model ID NCAIR1/N-ATLaS padà.

1. Python SDK

from ednai import EDNAi

ai = EDNAi(base_url="https://ednai-6znf.onrender.com")
result = ai.generate(
    "Ṣàlàyé ohun tí API jẹ́.",
    system="Dáhùn ní Yorùbá tó rọrùn.",
    temperature=0.2,
    max_tokens=300,
)
print(result.text)

2. TypeScript SDK

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({
  baseUrl: "https://ednai-6znf.onrender.com"
});
const result = await ai.generate("Kí ni API?");
console.log(result.text);

3. OpenAI-compatible HTTP

POST /v1/chat/completions
{
  "model": "NCAIR1/N-ATLaS",
  "messages": [
    {"role":"user","content":"Ṣàlàyé transformer attention."}
  ]
}

4. Prompt àti JSON mode

Lo system prompt láti sọ èdè, tone tàbí constraint. Má tan JSON mode fún ìdáhùn prose deede; tan-an nígbà tí app rẹ nílò JSON tó ṣeé ka lọ́nà machine.

5. Evaluation

ednai eval benchmarks/natlas_smoke.jsonl \
  --base-url https://ednai-6znf.onrender.com

Evaluation Workbench lè ṣe multilingual regression checks, JSON validity, required/forbidden strings àti latency.

6. Dataset Studio

Dataset Studio gba messages[] tàbí instruction/input/output JSONL, ó ń validate row kọ̀ọ̀kan, normalize data, ó sì ń fún ọ ní training-ready JSONL.

7. Fine-tuning

python fine_tuning/train_qlora.py \
  --dataset prepared.jsonl \
  --output-dir outputs/my-natlas-adapter

QLoRA/LoRA adapter náà bẹ̀rẹ̀ láti NCAIR1/N-ATLaS gan-an.

8. Runtime modes

  • ZeroGPU: hosted N-ATLaS runtime fún development àti demo; free quota lè queue tàbí tán fún ìgbà díẹ̀.
  • Local Transformers: load official N-ATLaS weights lórí server tirẹ.
  • OpenAI-compatible N-ATLaS: so EDNAi mọ́ endpoint tó ń ṣiṣẹ́ N-ATLaS gidi.

9. Speech Studio àti ASR

EDNAi ń lo speech-recognition models osise NCAIR ní POST /v1/audio/transcriptions, Python/TypeScript SDK, CLI àti Speech Studio.

result = ai.transcribe("audio.wav", language="yoruba")
print(result.text)
print(result.model)

EDNAi máa ń ṣàyẹ̀wò model ID tí ó padà kí ó bá èdè tí developer yàn mu; kò gba ASR model substitution.

10. Speech models osise

  • Nigerian English — NCAIR1/NigerianAccentedEnglish
  • Yorùbá — NCAIR1/Yoruba-ASR
  • Hausa — NCAIR1/Hausa-ASR
  • Igbo — NCAIR1/Igbo-ASR

Repository guide: docs/yo/ibere.md.

Use Case Studio

EDNAi ní workflow N-ATLaS mẹ́jọ: multilingual chatbot, translation, educational tools, cultural preservation, government services, digital inclusion, research applications àti original song-lyrics generation.

result = ai.run_use_case(
    "education",
    {
        "topic": "Photosynthesis",
        "learner_level": "JSS 2",
        "objective": "Ṣàlàyé bí ewéko ṣe ń ṣe oúnjẹ.",
        "format": "lesson_quiz"
    },
    language="yoruba"
)
print(result.text)

Developer tún lè lo GET /v1/use-cases, POST /v1/use-cases/{use_case}, TypeScript àti CLI. Song generation jẹ́ lyrics text nìkan; kò fi audio model míì kún submission.
