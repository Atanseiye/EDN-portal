EnglishYorùbá

EDNAi ń fún developer ní layer kan ṣoṣo láti pe, dán wò, ṣe adaptation àti deploy NCAIR1/N-ATLaS.

Python

from ednai import EDNAi

ai = EDNAi(base_url="https://your-gateway")
result = ai.generate(
    "Kí ni API?",
    system="Dáhùn ní Yorùbá."
)
print(result.text)

TypeScript

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({ baseUrl: "https://your-gateway" });
const result = await ai.generate("Kí ni API?");
console.log(result.text);
