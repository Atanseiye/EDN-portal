N-ATLaS naanị.

EDNAi anaghị ekwe ka model ọzọ dochie N-ATLaS. Qualifying runtime ga-egosi model ID dịka NCAIR1/N-ATLaS.

1. Python SDK

from ednai import EDNAi

ai = EDNAi(base_url="https://ednai-6znf.onrender.com")
result = ai.generate(
    "Kọwaa ihe API bụ.",
    system="Zaa n'Igbo dị mfe.",
    temperature=0.2,
    max_tokens=300,
)
print(result.text)

2. TypeScript SDK

import { EDNAi } from "@ednai/sdk";

const ai = new EDNAi({
  baseUrl: "https://ednai-6znf.onrender.com"
});
const result = await ai.generate("Kọwaa API n'Igbo.");
console.log(result.text);

4. Prompt na JSON mode

Jiri system prompt họrọ asụsụ, ụda olu ma ọ bụ iwu ọrụ. Hapụ JSON mode gbanyụrụ maka azịza nkịtị; gbanye ya naanị mgbe application chọrọ JSON ahaziri nke ọma.

5. Evaluation

ednai eval benchmarks/natlas_smoke.jsonl \
  --base-url https://ednai-6znf.onrender.com

Evaluation Workbench na-agba multilingual regression checks, JSON validity, okwu ndị a chọrọ/achọghị na latency.

6. Dataset Studio

Dataset Studio na-anabata messages[] ma ọ bụ instruction/input/output JSONL, na-enyocha row ọ bụla, na-normalize data ma wepụta training-ready JSONL.

7. Fine-tuning

python fine_tuning/train_qlora.py \
  --dataset prepared.jsonl \
  --output-dir outputs/my-natlas-adapter

QLoRA/LoRA adapter na-amalite kpọmkwem site na NCAIR1/N-ATLaS.

8. Runtime modes

  • ZeroGPU: hosted N-ATLaS runtime maka development na demo; free quota nwere ike ịbanye queue ma ọ bụ gwụ nwa oge.
  • Local Transformers: budata ma load official N-ATLaS weights na server gị.
  • OpenAI-compatible N-ATLaS: jikọọ EDNAi na endpoint nke na-arụ N-ATLaS n'ezie.

9. Speech Studio na ASR

EDNAi na-enye official NCAIR speech-recognition models site na POST /v1/audio/transcriptions, Python/TypeScript SDK, CLI na Speech Studio.

result = ai.transcribe("audio.wav", language="igbo")
print(result.text)
print(result.model)

EDNAi na-enyocha model ID ka ọ kwekọọ na asụsụ ahọpụtara; ọ naghị ekwe ASR model substitution.

10. Official speech models

  • Nigerian English — NCAIR1/NigerianAccentedEnglish
  • Yorùbá — NCAIR1/Yoruba-ASR
  • Hausa — NCAIR1/Hausa-ASR
  • Igbo — NCAIR1/Igbo-ASR
